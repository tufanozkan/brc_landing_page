# BRC Landing Page — Project Rules & Architecture Memory (.antigravity_rules.md)

> **Persistent Project Memory**: This document serves as the authoritative architectural blueprint and engineering memory for the BRC Kalıp & 4 El Plastik landing page codebase. Any engineer or AI agent joining this codebase MUST read and strictly adhere to the guidelines set forth here.

---

## Project Overview

- **Business Purpose**: BRC Kalıp & 4 El Plastik is an industrial engineering and plastic injection manufacturing company headquartered in Manisa, Turkey. This application is a high-performance, modern corporate landing page showcasing high-precision mold design (BRC Kalıp) and plastic injection capabilities (4 El Plastik), global manufacturing references, company milestones, and lead generation/contact mechanisms.
- **Business Goal**: Present a premium, fast, multilingual (Turkish & English) digital showcase to convert potential domestic and international manufacturing clients, highlight tier-1 partnerships, and deliver an exceptional user experience across all devices.
- **High-Level Architecture**: Next.js (Pages Router under `src/`) application rendered client/server-side, styled with Tailwind CSS v4, dynamic animations via Framer Motion, and localized with a custom React Context state layer (`LanguageContext`).

## Coding Conventions

### Naming Conventions
- **Components & Pages**: PascalCase for components (`Navbar.js`, `Footer.js`), camelCase/lowercase for page files matching routes (`index.js`, `plastic.js`, `contact.js`).
- **Contexts & Utilities**: PascalCase for Context components (`LanguageContext.js`), camelCase for utility modules (`translations.js`).
- **Variables & Functions**: camelCase (`language`, `setLanguage`, `isPlasticPage`).
- **CSS / Theme Variables**: Standardized Tailwind theme tokens (`charcoal`, `tealAccent`, `lightGray`, `orangeAccent`).

### Code Formatting & Structure
- Standard ES6+ JavaScript syntax with JSX.
- Path aliases: Always use `@/components/...`, `@/utils/...`, `@/styles/...` instead of relative relative imports (`../../`).
- Functional React components with hooks.
- Consistent Tailwind utility class order: Layout (`flex`, `grid`), Spacing (`p-`, `m-`), Sizing (`w-`, `h-`), Typography (`text-`, `font-`), Visuals (`bg-`, `border-`, `shadow-`), Transitions & Interactivity (`hover:`, `transition-`).

### Typing & Translation Conventions
- All user-facing copy MUST be registered in `src/utils/translations.js` under both `tr` and `en` blocks.
- Translations must be invoked using `t('section.keyName')` from `useLanguage()`.
- Avoid hardcoding static visible text directly in JSX components without corresponding i18n keys.

## Engineering Principles

1. **Separation of Concerns**: Presentation logic resides in `pages` and `components`, state management in `utils/LanguageContext.js`, and styling in Tailwind/`globals.css`.
2. **Feature Isolation & Reusability**: Common layout structures (Navbar, Footer, AnimatePresence page containers) wrap all pages via `_app.js`.
3. **Avoid Duplicated Logic**: Shared assets, translation strings, and navigation models are centralized.
4. **Modularity & Maintainability**: Clean, decoupled components that can be styled or updated independently without breaking sibling layouts.
5. **No Magic Values**: Colors and animations must be defined in `tailwind.config.js` or `globals.css` `@theme` block.

## API Conventions

- **Current State**: Contact form currently handles submit events on client side (`e.preventDefault()`).
- **Route Structure (Target)**: API routes will be created under `src/pages/api/` (e.g., `src/pages/api/contact.js`).
- **Validation**: Server-side validation for form inputs (email format, required fields).
- **Response Format**: JSON responses following standard format `{ success: boolean, message: string, data?: object }`.

---

## State Management

- **Global State**: Managed via React Context API in `src/utils/LanguageContext.js`.
- **Language State (`language`)**: Tracks selected language (`tr` | `en`). Persisted in `localStorage` key `'language'`.
- **Translation Resolver (`t`)**: Resolves dot-notation paths (e.g., `t('home.heroTitle')`) with fallbacks to key string if undefined.
- **Local Component State**: Handled via standard `useState` (e.g., mobile menu state `isMobileMenuOpen` in `Navbar.js`).

## UI/UX Rules

1. **Brand Aesthetics**: Deep industrial aesthetic featuring dark charcoal (`#303841`), tech teal accent (`#76ABAE`), crisp light gray backgrounds (`#F5F5F5`), and high-contrast orange CTA accents (`#FF5722`).
2. **Typography**: Google Font "Inter" for high legibility, clean modern hierarchy, and professional tone.
3. **Animations**: Smooth page transitions using Framer Motion (`opacity`, `y` translation), continuous keyframe marquees for partner logos, and micro-interactions on buttons/cards.
4. **Responsiveness**: Mobile-first responsive layouts with clean drawer navigation for screens `< 768px`.
5. **No Broken Placeholders**: High-resolution factory photography (`public/photos/`) and optimized SVG/PNG partner logos (`public/partners/`).

## Known Technical Debt

1. **Hero Video Slots**: Video background tags in `index.js` and `plastic.js` currently use gradient image overlays with commented-out HTML5 `<video>` tags awaiting actual MP4 video files (`brc_promo.mp4`, `plastic_promo.mp4`).
2. **Contact Form Backend**: `contact.js` form is client-only (`e.preventDefault()`) and requires integration with an email service (e.g., Resend, Nodemailer, or SendGrid) or API endpoint.
3. **Partner Logo Fallbacks**: `partnerLogos` array in `index.js` duplicates entries to achieve continuous marquee scrolling effect; consider refactoring into a dedicated infinite carousel component.

## Important Project Decisions

- **Tailwind v4 Integration**: `@import "tailwindcss"` with custom `@theme` tokens in `src/styles/globals.css` alongside `tailwind.config.js` to ensure compatibility and maximum styling performance.
- **Dynamic Navbar Branding**: Navbar logo dynamically switches between BRC Kalıp (`/logos/logo.png`) and 4 El Plastik (`/logos/4ellogo.png`) depending on whether the route is `/plastic`.
- **i18n Lightweight Architecture**: Custom React Context preferred over external heavy i18n frameworks to keep bundle size small and render times instantaneous.
